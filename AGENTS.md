# Panduan melanjutkan proyek

Pengguna menetapkan `instruksi.md` sebagai panduan kerja proyek ini. Baca berkas
tersebut sebelum mengubah kode. Gunakan bahasa Indonesia saat berkomunikasi.

Untuk melanjutkan sesi sebelumnya, baca `LANJUTKAN.md` dan
`dokumentasi/RIWAYAT_PENGEMBANGAN.md`. Keduanya menyimpan keputusan dan status
terakhir. Pengguna sering memperbarui `konsep_game.txt`; baca ulang saat diminta
mengikuti konsep, lalu cocokkan dengan keputusan terbaru dalam riwayat.

Pertahankan progres dan pengaturan pengguna. Jangan mengklaim executable terbaru
berhasil dijalankan jika pengujiannya diblokir Application Control Windows.
